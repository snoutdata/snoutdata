# Examples

Small, runnable projects against SnoutData Cloud. Each has its own README with the commands.

- [`node-todos`](./node-todos): a Node script that creates a table, inserts, updates and queries.
- [`web-notes`](./web-notes): one HTML page with email sign-up and private notes under row-level
  security.

Want another one? [Ask for it](https://github.com/snoutdata/snoutdata/issues/new?template=example-request.yml).
